# 设备部署与验收

状态：目标验收规范，预置 APK 尚未实现；以下不能用来宣称当前代码已经安装即用。

## 设备与系统部署

目标设备：Android 10（API 29）、1GB RAM、16GB 存储、15.6 英寸、1080×1920 竖屏。编译 SDK 可以高于设备版本；最终以依赖最低版本与 APK 元数据确认运行兼容性。

Device Owner 是 Android 系统管理身份，不是 Cloud 订阅或 root。需要完整锁定时，在部署阶段安装应用后，用 ADB 设置该身份；设备需满足无冲突的管理归属、账号等条件。先尝试清理账号，仍失败再考虑备份后恢复出厂，避免无谓丢数据。

当前上游包名的命令（实际操作前用 `adb devices` 选定设备）：

```text
adb -s <设备序列号> shell dpm set-device-owner top.lhlnb.easykiosk/.DeviceAdminReceiver
```

未来包名切换后，这条命令和组件名必须同步更新，不能混用。通过应用管理员入口解除 Device Owner；ADB 移除不保证在 release 构建上可用。恢复出厂只作为有备份且明确接受数据清除后的最后恢复方式。

安装后应先显式打开一次，处理系统必要授权，再验证锁定和重启。Android 安装完成不等于应用自动执行；需实现受管预配时另行设计部署流程。

## 功能验收矩阵（后续全部需执行并记录证据）

| 场景 | 通过标准 |
| --- | --- |
| 全新安装首次启动 | 不填网址、不注册 Cloud，直接全屏显示构建 URL，应用预设方向、常亮和锁定策略 |
| 管理员维护 | 手势 + 正确 PIN 能进入设置；错误 PIN 不可进入；修改 URL/PIN/布尔值重启后保留 |
| 升级安装 | 使用同签名且递增版本覆盖安装，不覆盖现场 URL/PIN，新增字段迁移明确 |
| 主动恢复预置 | 确认后恢复当前 APK 默认值；没有隐式退出设备管理 |
| 断网与恢复 | 出错有可恢复界面，网络恢复后重新加载；不永久停在错误页 |
| 应用/渲染器异常 | 分别验证进程终止、WebView 渲染器退出、OOM 与恢复；强行停止另记为系统限制 |
| 开机自启 | 普通权限与 Device Owner 分别测试至少 3 次重启，记录 ROM/机型和默认桌面条件 |
| 锁定 | 分别测试 Home、返回、最近任务、通知栏及管理员退出；不将普通安装等同于 Device Owner |
| 权限 | 无摄像头/麦克风权限也可展示普通网页；需要权限的网页在锁定前正确授权 |
| 1GB 长稳 | 连续运行 24～72 小时，记录可用内存、崩溃、重载次数、网络故障与页面可交互性 |
| APK | 离线于开发电脑可独立启动，无 Metro；签名/包名/版本/ABI/SHA-256/许可资源均正确 |

网页业务假死（例如连接断了但页面仍在）需网页心跳和业务恢复配合；不能只用进程看门狗判断业务健康。断电自动来电启动另需硬件验证。

## 模拟器说明

现有模拟器名为 `Kiosk_Android10_1080x1920_1G_16G`。部分 Emulator 会把 AVD 的 1GB 提升为 2GB；测试时用 `adb shell cat /proc/meminfo` 核对实际内存，不能只看配置文件。模拟器验证不替代实际展台硬件验收。
